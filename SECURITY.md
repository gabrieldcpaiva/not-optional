# Security Policy

## Supported Versions

This project is mostly documentation, JSON tokens, shell scripts, and example HTML. The supported version is the latest commit on the `main` branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Report them privately via GitHub's "Report a vulnerability" feature (private security advisories) on this repository.

When reporting, please include:
- A description of the vulnerability.
- Steps to reproduce it.
- Any potential impact.

We will reply as soon as we can, though we cannot make a hard SLA promise. Thank you for helping keep this project secure.
